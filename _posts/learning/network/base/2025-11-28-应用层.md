# 应用层

- 应用层
    - 应用层
        - 协议基于客户端-服务器(两个进程)方式
    - 域名系统
        - 域名系统概述
            - DNS: 分布式域名系统
            - 采用C-S方式
            - 域名转化为IP地址
        - 因特网的域名系统
            - 层次结构
            - 域名的标号都是英文字母和数字组曾
                - 每个标号不超过63个字符
                - 不区分大小写
                - 最低级写左边
                - 由多个标号组成的整个完整的域名不超过255个字符
        - 域名服务器
            - 区:
            - 按层次划分
            - 域名的解析过程
                - 主机向本地域名服务器的查询一般采用递归查询
                - 本地域名服务器向根域名服务器的查询通常采用迭代插叙
            - 高速缓存
    - 文件传送协议
    - 远程终端协议TELNET
    - 应用进程跨越网络的通信
    - 万维网WWW
    - 电子邮件
    - 动态主机配置协议DHCP
    - 简单网络管理协议SNMP
