# MongoDB的下载与安装

**MongoDB的下载与安装**

**1 下载MongoDB**

[https://www.mongodb.com/try/download/community](https://www.mongodb.com/try/download/community)

选择社区版 -> 选择版本 -> 选择os（linux）-> tgz

![](assets/images/learning/database/mongodb/mongodb-download-installation/1698037481848-d4fd90e5-1525-47e3-9f4d-c985a1ada1dd.png)

**2 安装MongoDB**

直接解压tgz文件

**2.1 安装依赖**

MongoDB 需要依赖openssl相关资源，必须先在linux中安装openssl10

安装make、rpm

**2.2 移动**

将解压完的MongoDB目录移动到/opt目录中并改名为mongoDB。

避免在root目录下安装，导致其他用户无权限

**2.3 创建数据存储目录**

MongoDB的数据可以通过配置存储在任意目录下，我们选择在 $MongoDB_HOME/ 目录下创建 data/db 目录（需要手动创建）

**2.4 创建日志存储目录**

MongoDB 的日志数据可以通过配置存储在任意目录下，我们选择创建在 $MongoDB_HOME/log 目录中，日志文件名为mongodb.log.

这个目录和日志文件同样需要手动创建

至此，MongoDB安装完毕
