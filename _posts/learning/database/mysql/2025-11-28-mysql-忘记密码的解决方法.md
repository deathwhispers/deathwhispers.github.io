# 忘记密码的解决方法

**前言**

在登录mysql时，发现密码错误，而之前记录密码的文件没有保存，所以智能重新设置密码了

![](/assets/images/learning/database/mysql/mysql-forget-password-solution/64d3bdb777015eed7986156dcf54a7e4.png)

**修改密码**

**1、检查mysql是否启动，如果已启动，则关闭mysql服务**

ps -ef | grep -i mysql

![](/assets/images/learning/database/mysql/mysql-forget-password-solution/35ec7d60dfa419801a59c4dbe1ac8532.png)

关闭mysql服务

service mysql stop

**2、修改MySQL配置文件 /etc/my.cnf**

增加代码

```plain text
[mysqld]
# 跳过授权
skip-grant-tables
```

登录MySQL时，跳过密码验证

重新启动MySQL并登录

![](/assets/images/learning/database/mysql/mysql-forget-password-solution/5433af82d851fbdaf3f21e5d0d0a23e7.png)

**3、修改密码**

update mysql.user set authentication_string=password(‘root_password’) where user=‘root’;

**4、重启MySQL服务**

此时就可以用新设置的密码登录服务了
