# redis安装

redis官方下载地址：[https://redis.io/download](https://redis.io/download)

redis 64位下载地址：[https://github.com/ServiceStack/redis-windows](https://github.com/ServiceStack/redis-windows)

修改redis.windows.conf文件，设置maxmemory 大小

![71262000532f0179c95d9b1bcc5dfee9](/assets/images/learning/database/redis/win-redis-installation/71262000532f0179c95d9b1bcc5dfee9.png)

![ec8b366d78ba926541c0f9fc710cd6c5](/assets/images/learning/database/redis/win-redis-installation/ec8b366d78ba926541c0f9fc710cd6c5.png)

设置redis密码

![0ecfe831b8b4d8e054dc1cea76a50a84](/assets/images/learning/database/redis/win-redis-installation/0ecfe831b8b4d8e054dc1cea76a50a84.png)

启动redis

```redis
redis-server.exe redis.windows.conf
```

将redis加入到windows的服务中（**service和loglevel前都是两个-**）

```bash
redis-server.exe –service-install redis.windows.conf –loglevel verbose
```
