# redis简单安装及后台运行

redis简单安装及后台运行

redis用c语言编写，在linux环境安装Redis需要将下载的源码进行编译，编译依赖gc++,如果没有gc++环境需要安装gcc

执行命令：yum install gcc-c++

[http://download.redis.io/releases/](http://download.redis.io/releases/)

wget [http://download.redis.io/releases/redis-4.0.8.tar.gz](http://download.redis.io/releases/redis-4.0.8.tar.gz)

tar xzvf redis-4.0.8.tar.gz

cd redis-4.0.8

make

原因：jemalloc重载了Linux下的ANSI C的malloc和free函数。

解决办法：请按照如下方式执行make编译命令

make MALLOC=libc

cd src

安装到指定目录

make install PREFIX=/usr/local/redis

复制redis.conf到redis/bin目录

设置后台启动：

vi redis.conf

将daemonize no 改成daemonize yes

启动redis

cd /usr/bin

./redis-server redis.conf

卸载redis：

rm -rf /usr/local/redis //删除安装目录

rm -rf /usr/bin/redis-* //删除所有redis相关命令脚本

rm -rf /root/download/redis-4.0.4 //删除redis解压文件夹
