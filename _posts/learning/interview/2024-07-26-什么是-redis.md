# 什么是 Redis ？

Redis ，全称 Remote Dictionary Server ，是一个基于内存的高性能 Key-Value 数据库。Redis 已经成为互联网公司在缓存组件选择的唯一。例如说，在各种公有云上，缓存服务都是提供的 Redis。再例如说，招聘简历要求上，都会要求掌握 Redis 。
