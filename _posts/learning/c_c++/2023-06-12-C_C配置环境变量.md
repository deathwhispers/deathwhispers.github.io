# C/C++配置环境变量

一、安装GNU的C++编译器

为了在 Windows 上安装 GCC，您需要安装 MinGW。为了安装 MinGW，请访问 MinGW 的主页 [www.mingw.org](http://www.mingw.org/)，进入 MinGW 下载页面，然后进行安装，

![Image.png](../../../assets/images/learning/c_c++/c_c++-config-env-variable/b308ae13445d0a42278241e87fc5a602.png)

![Image [1].png](../../../assets/images/learning/c_c++/c_c++-config-env-variable/12d1a6eeadfdba0c952c139fdbf67a5a.png)

![Image [2].png](../../../assets/images/learning/c_c++/c_c++-config-env-variable/7fd12e6ace1d29aac386e31a4cfd43d7.png)


添加你安装的 MinGW 的 bin 子目录到您的 **PATH** 环境变量中，这样您就可以在命令行中通过简单的名称来指定这些工具。

1、在命令行（cmd）输入g++ –version查看g++版本，确认path是否生效。
